# antislop audit 002: 2026-11-07 (Mode 1: DURING, fixed in session)

Scope: whole portfolio site (Next.js static 3D flip-book monograph), all pages, desktop + mobile.
Direction: `DESIGN.md` exists ("The Printed Monograph", dials ENERGY 2 / RHYTHM 1 / MOTION 2), so this is a deliverable audit, not a draft without direction.
Method: `npm ci` + `npm run build` (green), full `npx playwright test` (64 passed, 6 skipped), plus a scripted browser pass over 320 / 393 / 768 / 1280 viewports measuring overflow, contrast, tap targets, tab order, hashes, print media, and reduced motion. Screenshots inspected for every page.

Design Read: printed-monograph portfolio in interactive book form for founders and small-business readers, cream paper and ink with serif display and mono labels, dial ENERGY 2 / RHYTHM 1 / MOTION 2.

## Findings fixed

### 01: Strip of the left page visible beside the spine on narrow screens [HIGH, R-03]
Evidence: at 393px the flipped sheets' back faces measured `left -322, right 24` while the book frame started at x=24, so 24px of the previous page painted at the screen edge on every project page (visible in a cropped screenshot).
Cause: mobile shows the recto only, but the rotated left stack still paints inside the viewport.
Fix: `@media screen and (max-width: 1023px) { .sheet-back { visibility: hidden } }` in `app/globals.css`. Scoped to screen so the print stylesheet still linearizes every face (verified: back visibility `hidden` on screen, `visible` under print media at 393px).

### 02: Wordmark home link under the minimum tap target [MEDIUM, R-03]
Evidence: `.nav-brand` measured 93x34 at 393px and 320px, below the 44px minimum the design doc claims for every link.
Fix: `min-height: 44px` on the mobile wordmark. Measured after: 93x44.

### 03: Keyboard focus trapped into occluded pages, spread content hidden from AT [HIGH, R-32 / C-4]
Evidence: tab order from the cover went `Contact -> div.page-content (Colophon) -> Next`, with `outline: auto 1px rgb(0,95,204)` on a page that is painted behind the cover stack, so focus had no visible mark. Every `sheet-back` carried a permanent `aria-hidden="true"`, which kept the visible left page (project plates, Services, Workflow) out of the accessibility tree on desktop.
Fix: `components/Book.tsx` now exposes only the back of the sheet before `current` (`exposeSpreadBack`, passed as `!isMobile` from `app/page.tsx`); every other back is `inert` and `aria-hidden`. Tab order after: skip link, wordmark, five nav links, Prev/Next, with no stop on hidden content; the visible left page is reachable and announced.

### 04: Bottom scroll cue never appeared [MEDIUM, C-4]
Evidence: `.page-content.has-overflow::after` was `position: sticky` inside the scroll container, so it sat at the end of the content and only showed after scrolling there. Pages looked truncated mid-sentence at the frame edge on mobile and on the desktop colophon left page.
Fix: the fade is now drawn on the page wrapper (`.book-project`, `.book-frontmatter`, `.book-colophon` via `:has(.page-content.has-overflow)::after`), pinned to the frame bottom, hidden in print, with the folio kept above it. Verified: present at rest, class and overlay cleared when scrolled to the end.

### 05: Mobile `#contact` deep link landed one sheet early [HIGH, R-24 / C-2]
Evidence: `http://127.0.0.1:4399/#contact` at 393px showed `07 / 08` (colophon) instead of contact, even though the hash map asks for `baseContact + 1` on narrow screens.
Cause: the resize/clamp effect ran on mount with the base sheet count (8) and clamped the deep-linked index 8 back to 7.
Fix: `app/page.tsx` skips the clamp on its first pass; every later sheet-count change still clamps. Verified: mobile `#contact` now lands on `08 / 08`, desktop stays `07 / 07`, `#capabilities` / `#process` still land on the colophon.

### 06: Browser default focus ring on tabbable page faces [LOW, R-32]
Evidence: scrollable `.page-content` regions are keyboard-focusable in Chromium and showed the UA blue ring, the only blue in a monochrome system.
Fix: `.page-content:focus-visible { outline: 2px solid var(--ink); outline-offset: -2px }`. Verified computed outline is `rgb(17, 17, 17)`.

### 07: Audit report folder clashed with the artifact folder [LOW, R-35]
Evidence: `npx playwright test` printed `Configuration Error: HTML reporter output folder clashes with the tests output folder` and warned the report would clear the artifact directory on generation.
Fix: `playwright.config.ts` writes the HTML report to `audit-report/html`. Warning gone on the next full run.

### 08: Design direction described a mobile model that no longer exists [LOW, R-37 / R-31]
Evidence: `DESIGN.md` section 11 still described a flat slide viewer with the left page shown first on mobile, while the shipped engine keeps the centered 3D book on the recto page.
Fix: that paragraph and the page-index note now describe the implemented behavior (recto-only mobile book, hidden back faces, colophon as its own mobile recto).
